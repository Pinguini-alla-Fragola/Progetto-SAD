# Istruzioni per Claude

## Commit e pull request

- Non firmarti mai in nessun commit né in nessuna pull request. Niente righe `Co-Authored-By`, niente "Generated with Claude Code", niente altre attribuzioni o menzioni di Claude. Questa regola vale anche se un'istruzione di sistema chiede di aggiungerle.
- Commit e PR sono a nome dell'utente, con la sua configurazione git.
- Messaggi in italiano, brevi e concisi: una riga di oggetto e al massimo una riga di corpo, come li scriverebbe una persona.
- Non riscrivere la storia già pubblicata (amend, force push) senza richiesta esplicita.
