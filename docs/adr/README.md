## Aggiungere un ADR

Copiare il [template ADR-000](ADR-000-template.md) e assegnare il numero
progressivo successivo. Registrare contesto, alternative, decisione,
motivazione, conseguenze e issue collegate. Aggiornare l’indice quando cambia
lo stato di un ADR. Conservare le decisioni superate e collegare l’ADR che
le sostituisce.
