# Registro delle decisioni

La cartella mantiene la struttura del template per documentare le future
decisioni significative. Non sono ancora presenti decisioni adottate.

Per una nuova decisione, copiare [ADR-000-template.md](ADR-000-template.md),
assegnare il numero progressivo e indicare contesto, alternative, motivazione,
conseguenze e issue collegate. Conservare le decisioni superate collegando
il documento che le sostituisce.
