# Scenari di qualità

Documentare ogni scenario con la struttura del template:

| Sorgente | Stimolo | Ambiente | Artefatto | Risposta | Misura della risposta |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

Registrare anche attributo di qualità, priorità, motivazione, fonte e metodo
di verifica. Le soglie non ancora concordate sono proposte da validare.
Collegare ciascuno scenario alle esigenze PICUS e alle issue pertinenti.

L'analisi di riferimento è conservata nel
