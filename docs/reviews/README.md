## Note di rilascio per la Sprint Review

In GitHub, apri **Releases → Draft a new release**, seleziona il tag dello
sprint e il tag precedente, quindi scegli **Generate release notes**. Le
[categorie](../../.github/release.yml) usano le etichette delle PR integrate.
Rivedi la bozza e aggiungi i link alla demo e ai materiali della Sprint Review
prima di pubblicare.
